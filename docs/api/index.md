# API

API предоставляет доступ к функциям рекомендательной системы фильмов: сохранение истории просмотров, оценка фильмов и получение персональных рекомендаций от ИИ-модели.

## Основные операции

- `POST /recommendations` — получить персональные рекомендации;
- `GET /users/{userId}/viewings` — получить историю просмотров пользователя;
- `POST /users/{userId}/viewings` — добавить фильм в историю просмотров;
- `PATCH /viewings/{viewingId}` — изменить оценку просмотренного фильма.

## Спецификация

Полное описание API находится в файле `openapi.yaml`.
