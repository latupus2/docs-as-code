# Model Card

## Общая информация

**Название модели:**  
all-MiniLM-L6-v2

**Источник:**  
https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2

**Автор / организация:**  
Организация sentence-transformers на Hugging Face. Имена конкретных авторов не указаны.

**Задача модели:**  
Преобразование предложений и коротких абзацев в 384-мерные векторы. Векторы можно использовать для семантического поиска, кластеризации и сравнения текстов по смыслу.

**Язык:**  
Английский.

## Использование в проекте

В рекомендательной системе фильмов модель превращает текстовое описание фильма (название, жанр, краткий сюжет) в вектор. Система сравнивает векторы фильмов, которые пользователь посмотрел и высоко оценил, с векторами фильмов из каталога, которые он ещё не видел. Чем ближе векторы, тем выше `score` рекомендации.

## Входные данные

Текст на английском языке.

## Выходные данные

Вектор из 384 чисел для каждого входного текста.

## Метрики качества

Набор ArguAna из бенчмарка MTEB (версия MTEB v1.12.75), значение 50,17.

## Ограничения
 
- текст длиннее 256 токенов обрезается;
- при обучении длина последовательности была ограничена 128 токенами;
- модель предназначена как кодировщик предложений и коротких абзацев.
 
Потенциальное ограничение для нашего проекта: модель помечена как английская, поэтому описания фильмов на других языках могут кодироваться хуже.
 
Потенциальное ограничение для нашего проекта: близость текстов не обязательно равна близости вкусов.
 
## Не рекомендуется использовать

- для текстов на других языках без отдельной проверки качества;
- для длинных документов, если важен весь текст;
