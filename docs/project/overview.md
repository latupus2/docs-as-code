# Рекомендательная система фильмов 

Сервис автоматически подбирает фильмы на основе интересов пользователя. Вместо долгого поиска по каталогу пользователь получает персонализированный список фильмов.

Основные пользователи:

- пользователь
- администратор

Основные функции:

- сохранение истории просмотров;
- оценка просмотренных фильмов;
- получение персональных рекомендаций;

## Комплект документации

1. **Описание проекта** — для всех участников; кратко объясняет, что за сервис, кто им пользуется и какие у него функции.
2. **Требования** — для разработчика и заказчика; фиксирует, что система должна уметь и какие у неё ограничения.
3. **Архитектура системы** — для разработчиков; показывает, из каких компонентов состоит сервис (хранилище истории просмотров, модель, интерфейс) и как они взаимодействуют.
4. **Документация ML-модели** — для разработчиков; описывает данные, способ построения рекомендаций, метрики качества и ограничения модели.
5. **Описание данных** — для разработчиков и администратора; поясняет структуру каталога фильмов, истории просмотров и оценок.
6. **Документация API** — для разработчиков интерфейса; описывает запросы, по которым сохраняются просмотры и оценки и выдаются рекомендации.
7. **Руководство пользователя** — для зрителя; объясняет, как смотреть, оценивать фильмы и получать рекомендации.
8. **Руководство администратора** — для администратора; описывает управление каталогом фильмов и обновление данных.
