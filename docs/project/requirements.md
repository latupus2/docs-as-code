# Требования

## User Stories

### US-01. Ведение истории просмотров

Как пользователь,
я хочу, чтобы система сохраняла историю моих просмотров,
чтобы рекомендации учитывали то, что я уже смотрел.

Критерии приёмки:

- система сохраняет каждый просмотренный фильм в истории пользователя;
- пользователь может открыть список просмотренных фильмов;
- если история пуста, пользователь видит сообщение, что просмотренных фильмов пока нет.

### US-02. Оценка просмотренных фильмов

Как пользователь,
я хочу оценивать просмотренные фильмы,
чтобы рекомендации лучше соответствовали моим вкусам.

Критерии приёмки:

- пользователь может поставить оценку просмотренному фильму;
- оценка сохраняется и отображается в карточке фильма;
- пользователь может изменить ранее поставленную оценку.

### US-03. Получение персональных рекомендаций

Как пользователь,
я хочу получать список рекомендованных фильмов,
чтобы быстрее выбрать, что посмотреть.

Критерии приёмки:

- система показывает список фильмов, которые пользователь ещё не смотрел;
- рекомендации формируются на основе истории просмотров и оценок;
- если данных для рекомендаций недостаточно, пользователь получает сообщение об этом.

## Use Case

### UC-01. Получение персональных рекомендаций

Актор: пользователь

Цель: получить список фильмов, подобранных на основе истории просмотров и оценок.

Предусловие: у пользователя есть история просмотров или оценки фильмов.

Основной сценарий:

1. Пользователь открывает раздел рекомендаций.
2. Система передаёт историю просмотров и оценки ML-модели.
3. ML-модель подбирает фильмы, похожие на те, что пользователь смотрел и высоко оценил.
4. Система получает список рекомендаций от модели.
5. Пользователь видит список фильмов, которые он ещё не смотрел.

Альтернативный сценарий:

Если данных для рекомендаций недостаточно (история просмотров пуста), система сообщает, что нужно посмотреть и оценить несколько фильмов.

Результат: пользователь получил персональный список рекомендаций или сообщение о том, что для их построения не хватает данных.
